# Sistem Diagnosa Awal Maag vs GERD

Website cerdas untuk mendeteksi apakah gejala kamu lebih condong ke **Maag** atau **GERD** menggunakan AI (Naive Bayes).

Fitur:
- Animasi halus & desain modern
- Tekan Enter = langsung diagnosa
- Rekomendasi obat awal


Apa yang dipakai?
- HTML + CSS + JavaScript
- Naive Bayes Classifier
- FontAwesome + Google Fonts
